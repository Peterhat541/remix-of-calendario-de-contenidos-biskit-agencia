

# Actualizar FROM_EMAIL

## Acción
Actualizar el secreto `FROM_EMAIL` con el siguiente valor:

```
Biskit Agencia <noreply@biskitagencia.com>
```

## Siguiente Paso
Al aprobar este plan, te mostraré el campo donde debes pegar exactamente ese valor.

## Resultado
Una vez configurado, los correos del calendario se enviarán desde `noreply@biskitagencia.com` y los clientes verán "Biskit Agencia" como remitente.
